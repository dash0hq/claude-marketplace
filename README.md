# Claude Code toolchain

## ✨ Marketplace

Plugins:
- [agent-skills](https://github.com/dash0hq/agent-skills): OpenTelemetry skills and reference documentation for AI coding assistants
- [dash0-agent-plugin](https://github.com/dash0hq/dash0-agent-plugin): OpenTelemetry observability for Claude Code sessions — captures tool calls, LLM invocations, token usage, and errors as OTel traces

## 🚀 How to use ?

```bash
/plugin marketplace add dash0hq/claude-marketplace
/plugin install dash0-agent-skills@dash0
/plugin install dash0-agent-plugin@dash0
```
